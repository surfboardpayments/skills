Do not edit these by hand; edit the guide on the marketing site and re-run `npm run skills`.

- [Store Management](./store-management.md): Create, update, verify, and manage in-store and online stores using the Surfboard Payments Store APIs.
- [Account & Service Provider Management](./account-management.md): Create merchant and partner accounts, manage user roles, register service providers, and configure external notifications via the Surfboard API.
- [Partner Branding](./partner-branding.md): Configure white-label branding for terminals and payment pages. Set colors, fonts, logos, and cover images at the partner level via API or Partner Portal.
- [Service Providers & Split Payouts](./service-providers.md): Route a share of each payment to a third party with Surfboard Flow. Onboard a service provider, link it to a merchant, and set the split on the order.
- [AI Product Images and Branding](./ai-merchandising.md): Turn a phone photo into a usable product image and a website into a branded portal. Two endpoints that remove the design work from onboarding a merchant.
